# Komentář k zákonu č. 529/1991 Sb., o ochraně topografií polovodičových výrobků

Otevřený komentář k zákonu o ochraně topografií polovodičových výrobků — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; předmět a podmínky ochrany, přihláška a zápis u Úřadu průmyslového vlastnictví, doba a účinky ochrany, výmaz a rejstřík.

Konsolidované znění: dokument e-Sbírky `SB-1991-00529_2022-02-01`.
